# NIGHT CLUB — Telegram Mini App · demo build 0.2

Обновлённый мобильный игровой клуб на React + Vite с сервером Node.js/Express. Внутри — шесть режимов, плавные переходы и анимации, баланс в демо-₽, история раундов и интеграция с Telegram Mini Apps.

## Что добавлено

- **Midnight Slots** — слот-машина с анимацией барабанов и таблицей выплат.
- **Roulette Noir** — европейская рулетка 0–36, красное/чёрное, зеро и чёт/нечет.
- **Neon Crash** — заранее выбранный автовыход и анимация растущего множителя.
- **Dice Club** — прогноз числа выше или ниже порога.
- **Double Flip** — выбор орла или решки.
- **Mines** — поле 5×5, 3/5/8 скрытых мин, открытие клеток и возможность забрать текущий приз.

Результаты раундов, скрытые мины и изменения баланса обрабатываются сервером, а не только интерфейсом.

## Важно: это только демо

Баланс отображается в **демо-₽** — это игровые очки, которые не имеют денежной стоимости. Их нельзя купить, продать, передать или вывести. Депозитов, платежей и реального денежного кошелька в проекте нет. Это не настоящее казино для игры на деньги.

Баланс и история хранятся в оперативной памяти сервера и сбрасываются после его перезапуска. `schema.sql` — пример схемы для будущей разработки; он пока не подключён к приложению. Этот MVP не подходит для приёма реальных ставок или денег.

## Как запустить на компьютере

Нужны Node.js 20+ и npm.

1. Распакуй ZIP в отдельную папку.
2. Открой терминал в этой папке.
3. Установи зависимости:

   ```bash
   npm install
   ```

4. Запусти клиент и API:

   ```bash
   npm run dev
   ```

5. Открой адрес Vite из терминала, обычно `http://localhost:5173`. API запускается на порту `3001`.

При локальном запуске без `BOT_TOKEN` используется один демо-пользователь. Такой обход предусмотрен только для разработки; в `NODE_ENV=production` он недоступен.

## Подключение к Telegram для теста

1. Создай бота через [@BotFather](https://t.me/BotFather).
2. Скопируй `.env.example` в `.env` и укажи `BOT_TOKEN`. Не добавляй токен в клиентский код и не публикуй его.
3. Опубликуй клиент на HTTPS-адресе и укажи этот адрес для Mini App в настройках бота.
4. Клиент передаёт исходный `initData` в заголовке `X-Telegram-Init-Data`; сервер проверяет подпись и `auth_date`, когда задан `BOT_TOKEN`.

Файл `.env` сам по себе не загружается — переменные нужно экспортировать в shell либо добавить загрузчик dotenv. Например, в shell с поддержкой `source`:

```bash
set -a && source .env && set +a && npm run dev
```

## Сборка

```bash
npm run build
NODE_ENV=production BOT_TOKEN=... npm start
```

Если существует `dist/`, сервер раздаёт собранный клиент. Для публикации нужен HTTPS и постоянное хранилище — в текущем MVP данные хранятся в памяти.

## API-методы

- `GET /api/health`, `GET /api/me`
- `POST /api/demo/bonus`
- `POST /api/slots/spin` — `{ "bet": 50 }`
- `POST /api/roulette/spin` — `{ "bet": 50, "choice": "red" }`
- `POST /api/crash/play` — `{ "bet": 50, "cashoutAt": 2.0 }`
- `POST /api/dice/play` — `{ "bet": 50, "target": 50, "side": "over" }`
- `POST /api/coinflip/play` — `{ "bet": 50, "choice": "heads" }`
- `POST /api/mines/start` — `{ "bet": 50, "mines": 3 }`
- `POST /api/mines/pick` — `{ "index": 4 }`
- `POST /api/mines/cashout`

## Если когда-нибудь делать денежный продукт

До любой денежной функции нужно определить страну запуска и лицензионный путь, пройти юридическую и комплаенс-проверку, спроектировать проверку возраста и географии, постоянный финансовый журнал, транзакции БД, защиту платёжных webhook, лимиты ответственной игры, аудит RNG/математики, антифрод и мониторинг. Ничего из этого не реализовано в качестве денежной инфраструктуры здесь. Не подключай к проекту платёжные реквизиты без отдельного профессионального проектирования.


## Самый простой запуск на Windows

1. Установи Node.js LTS с https://nodejs.org/ (если ещё не установлен).
2. Распакуй архив полностью в обычную папку, не запускай изнутри ZIP.
3. Дважды щёлкни `УСТАНОВИТЬ.bat`. Он использует `npm.cmd`, поэтому не зависит от политики выполнения PowerShell-скриптов. Скрипт установит зависимости и выполнит сборку frontend.
4. После успешного завершения дважды щёлкни `START.bat`.
5. Открой `http://localhost:5173`.

Если установка или сборка завершается ошибкой, оставь окно открытым и пришли полный текст ошибки. Не нужно менять ExecutionPolicy или отключать защиту Windows.
